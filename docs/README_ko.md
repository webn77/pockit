# pockit (한국어 가이드)

**결정론적 규칙 게이트 및 자동 평가 기능을 내장한 기업용 LLM 에이전트 엔진**

`pockit`는 금융, 의료, 법률 등 규제가 엄격하고 안전성이 필수적인 고위험 도메인(High-Stakes Domains)에서 LLM 에이전트를 실 서비스(Production) 수준으로 구축하기 위한 오픈소스 스타터킷 및 프레임워크입니다.

본 프로젝트는 에이전트의 완전 자율 행동을 신뢰하는 대신, **LangGraph** 오케스트레이션을 통해 에이전트 동작의 제어 흐름을 명시하고, 의무적인 **RAG 정보 검색**을 거치게 하며, 실행 직전 단계에서 **결정론적 규칙 게이트(Rule-Based Access Control & Threshold Gates)**로 승인 여부를 검증하고, 이를 **정량적 회귀 평가 하네스**를 통해 최종 검증합니다.

## 1. 왜 pockit 인가요? (Enterprise PoC의 현실적 문제)

많은 기업에서 AI 에이전트 도입을 위한 PoC(개념 검증)를 수행하지만, 보안 및 통제성 검증 단계를 통과하지 못해 프로덕션 배포에 실패합니다.
* **설명 가능성(Explainability) 부족**: LLM이 왜 특정 도구를 호출하고 결과를 냈는지 감사(Audit)할 수 없음.
* **비결정론적 행위**: 프롬프트 지시사항을 무시하고 임의로 대출 승인, 송금, 개인정보 노출 등의 행위를 할 우려.
* **정적 권한 모델의 한계**: 사용자 권한(RBAC)이 에이전트 및 하위 툴 호출 단방향으로 전파 및 검증되지 않음.

`pockit`는 **"자연어 의도 파악(LLM)"과 "도구 실행 제어(결정론적 코드)"를 분리**하여 이 문제를 근본적으로 예방합니다.

## 2. 핵심 기능 및 구조

본 프레임워크는 도메인 중립적인 **Core(엔진 코어)**와 도메인 의존적인 **Adapter(어댑터)** 구조로 설계되어 있어, 비즈니스 로직에 맞게 어댑터만 교체하면 다른 도메인으로 손쉽게 이식이 가능합니다.

### A. 엔진 코어 (Core - 변경 없이 그대로 재사용 가능)
* **LangGraph 오케스트레이터**: 에이전트 상태, 분기 로직 및 Human-in-the-loop 인터럽트(관리자 수동 승인) 관리.
* **강제 RAG 파이프라인**: 에이전트가 답변을 생성하기 전에 반드시 사내 정책 문서 등 신뢰할 수 있는 가이드라인을 강제로 참조하도록 흐름 구성.
* **3단계 게이트 엔진 (`risk_gate`)**: 권한 및 요청 금액의 임계치에 따라 즉시 허용(`ALLOW`), 승인 대기(`REVIEW` - HITL 인터럽트 유발), 즉시 거부(`BLOCK`)로 분류하여 결정론적 필터링.
* **평가 하네스 (Evaluation Harness)**: 골든셋 데이터셋(`golden.jsonl`)을 기준으로 에이전트의 답변, RAG 검색 품질, 도구 선택 정확도 등을 자동으로 정량 평가.
* **MCP (Model Context Protocol) 래퍼**: 검증된 안전한 인터페이스만을 외부 MCP 클라이언트에 안전하게 노출.

### B. 어댑터 (Adapter - 도메인 변경 시 교체 필요)
1. **도구 인터페이스(Tools)**: API 연동용 함수(예: 송금 API, 처방조회 API).
2. **정책 지식베이스(Knowledge Base)**: RAG 검색 대상 문서(예: 환불 정책서, 의료 가이드라인).
3. **결정론적 게이트 규칙(Gate Rules)**: 코드화된 정책 조건(예: 거래 제한 금액 설정, 직급 권한 맵).
4. **평가 골든셋(Golden Set)**: 에이전트 동작 정량 평가용 테스트 시나리오셋.

## 3. 고위험 도메인 확장 예시

어댑터 4종만 변경하면 다음과 같은 고위험 산업군으로 신속하게 이식할 수 있습니다.

| 도메인 | 정책/RAG 어댑터 | 도구 어댑터 | 안전 게이트 규칙 (결정론적) |

| **핀테크 / 결제** *(본 예시)* | 환불 및 정산 규정 문서 | 송금 API, 수수료 계산 | - 100만 원 초과 거래: 관리자 승인(`REVIEW`) 필요<br>- 150만 원 초과 거래: 차단(`BLOCK`) |

## 4. 퀵 스타트 (결제 PoC 실행 방법)

본 리포지토리에는 기본적으로 **결제(Payment) 에이전트** 구현체가 동봉되어 있습니다.

### 필수 조건

* Python 3.10 이상
* Anthropic Claude API 키가 발급된 계정 또는 구독 환경

### 설치 및 설정

```bash
# 레포지토리 복사
git clone https://github.com/your-username/pockit.git
cd pockit

# 가상환경 구축 및 라이브러리 설치
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# 환경변수 파일 복사 및 설정
cp .env.example .env
```

### 실행

```bash
# 1. Chroma DB에 금융 정책 문서 인덱싱 (최초 1회 실행)
python -m src.rag.retriever

# 2. ALLOW / REVIEW / BLOCK 시나리오별 데모 실행
python -m src.run_demo

# 3. 전체 평가 데이터셋 실행 및 정량 평가지표 리포트 확인
python -m src.eval.run_eval
```
