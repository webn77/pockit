# GOAL-1 — 고위험 도메인 LLM 가드레일 스타터킷

## 목표 (한 문장)
> 고위험 도메인에서 LLM 에이전트를 **안전하게** 운영하는 가드레일 하네스를 만들어,
> 결제로 검증하고 → AT-17에 이식해 재사용을 증명하고 → 오픈소스 스타터킷으로 공개한다.

## 왜 (Why now)
- "AI Agent / RAG / Tool Calling / MCP / LangGraph / 평가 데이터셋" 역량을 요구하는 채용 시장 대응
- 벤치마킹 결과 기존 레포는 데모·문서챗봇 위주 → **통제(게이트)+정량평가를 같이 갖춘 스타터가 공백**
- 포트폴리오를 "앱 하나"가 아니라 **방법론 자산**으로 격상

## 성공 기준 (Definition of Success)
- [ ] Phase 1: 결제 에이전트가 end-to-end 동작 + 평가 지표표 공개
- [ ] Phase 2: AT-17 이식 시 코어 변경 없이 어댑터 4개 교체만으로 동작 (재사용 증명)
- [ ] Phase 3: 스타터킷 public repo 공개 + README (남이 자기 도메인 꽂아 쓸 수 있음)
- [ ] 포트폴리오 AT-23 등재
